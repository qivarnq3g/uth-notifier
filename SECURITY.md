# Security policy

## Supported versions

Security fixes are provided for the latest revision of the default branch.
Older revisions and private deployments are not supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting or a private security advisory for
this repository. Do not publish exploit details, credentials, private
infrastructure identifiers, Telegram data, payment data or user-provided
content in an issue.

If private reporting is unavailable, open a minimal issue requesting a private
contact channel. Include no sensitive evidence in that issue.

Reports should describe the affected component, prerequisites, impact and a
minimal reproduction with synthetic data. Revoke any credential accidentally
included in a report before sending it.

## Scope

The project does not authorize testing against third-party services,
production deployments or users. Use local fixtures and systems you own or
have explicit permission to test.
